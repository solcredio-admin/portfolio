Home network on TP-Link Omada

Built a managed home network using a TP-Link ER605 router, an Omada 8-port switch and an EAP110 outdoor access point, which extends Wi-Fi coverage across the whole block. The Omada controller is self-hosted on a local server and manages every access point, from adoption to configuration.

The network handles static IP assignments and VLAN-style device segmentation, and it connects every device in the house, including smart TVs and desktop workstations. All cabling is custom: hand-crimped RJ45 patch cables for the patch panel and outdoor-rated Cat6 runs for longer distances.

TP-Link ER605, Omada Controller, EAP110 Outdoor AP, patch panel, Cat6 cabling, static IP management, network design
